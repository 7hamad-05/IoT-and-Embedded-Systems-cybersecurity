## 📚 Books

Books covering IoT security, hardware hacking, firmware analysis, and penetration testing.

### Practical IoT Hacking

* **Author:** Fotis Chantzis, Ioannis Stais, Paulino Calderon, Evangelos Deirmentzoglou, Georgios Kallitsis
* **Focus:** IoT penetration testing, hardware, firmware, network security, and exploitation
* **Level:** Intermediate → Advanced
* **Link:** `https://practical-iot-hacking.com/`

### The IoT Hacker's Handbook

* **Author:** Aditya Gupta
* **Focus:** Hardware hacking, firmware analysis, embedded systems, IoT protocols, and exploitation
* **Level:** Intermediate → Advanced
* **Link:** `https://link.springer.com/book/10.1007/978-1-4842-4300-8`

### IoT Penetration Testing Cookbook

* **Authors:** Aaron Guzman & Aditya Gupta
* **Focus:** Practical IoT penetration testing techniques and attack methodologies
* **Level:** Intermediate → Advanced
* **Link:** `https://www.packtpub.com/en-us/product/iot-penetration-testing-cookbook-9781787280571`

## 📖 Standards & Security Methodologies

Security standards and methodologies useful for structured IoT security testing.

### OWASP IoT Security Testing Guide

* **Focus:** IoT security testing methodology and test cases
* **Link:** `https://owasp.org/www-project-iot-security-testing-guide/`

### ETSI EN 303 645

* **Focus:** Cybersecurity requirements for consumer IoT products
* **Use:** Security requirements, assessment, and compliance mapping
* **Resources:** `https://www.etsi.org/deliver/etsi_en/303600_303699/303645/03.01.02_20/en_303645v030102a.pdf`

### ETSI TS 103 701

* **Focus:** Conformance assessment of IoT cybersecurity provisions
* **Use:** IoT security testing and evidence collection
* **Resources:** `https://cdn.standards.iteh.ai/samples/etsi/etsi-ts-103-701-v2-1-1-2025-05-/4a1572691ef14bafb110dd43d8a4ff01/etsi-ts-103-701-v2-1-1-2025-05-.pdf`

## ⭐ Recommended Learning Order

For someone starting from scratch:

```text
01. Networking Fundamentals
        ↓
02. Linux & Embedded Linux
        ↓
03. Basic Electronics
        ↓
04. UART
        ↓
05. SPI & I2C
        ↓
06. JTAG / SWD
        ↓
07. PCB Inspection
        ↓
08. Firmware Extraction
        ↓
09. Firmware Analysis
        ↓
10. Reverse Engineering
        ↓
11. IoT Protocols
        ├── MQTT
        ├── CoAP
        ├── RTSP
        └── ONVIF
        ↓
12. IoT Pentesting Methodology
        ↓
13. Hands-On Labs
        ↓
14. Real-World IoT Security Assessments
        ↓
15. Advanced Research & Exploit Development
```

---

> **Goal:** Learn the technology → Understand the attack surface → Practice in a lab → Perform security testing → Research vulnerabilities → Document the findings.
